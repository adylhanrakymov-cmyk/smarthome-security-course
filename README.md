🏠 Smart Home Security System (by Rakymov Adylkhan)

Курсовой проект: разработка системы домашней безопасности на базе сетевых устройств.

📌 О проекте

Smart Home Security System — программный прототип системы домашней безопасности, предназначенный для мониторинга событий и обнаружения потенциальных угроз с использованием виртуальных сетевых датчиков.

Система позволяет управлять режимом охраны, имитировать сигналы датчиков, обнаруживать нарушения безопасности и сохранять историю событий.

⚙️ Основные возможности

- Включение и отключение режима охраны.
- Имитация работы датчика движения PIR.
- Имитация открытия входной двери.
- Имитация открытия окна.
- Автоматическая активация тревоги при обнаружении опасного события в режиме охраны.
- Сброс тревожного состояния.
- Просмотр подключённых устройств и их IP-адресов.
- Ведение журнала событий.
- Сохранение истории событий в базе данных SQLite.
- Веб-интерфейс для мониторинга и управления системой.

🚀 Запуск проекта

1. Установить Python.
2. Установить необходимые зависимости:

pip install -r requirements.txt

3. Запустить приложение:

python main.py

4. Открыть браузер и перейти по адресу:

http://127.0.0.1:5000

⚠️ Особенности реализации

Проект представляет собой программный прототип. Для имитации работы сетевых устройств используются три виртуальных датчика. Физическое подключение оборудования и установка системы в реальном жилом помещении не предусмотрены текущей реализацией.

🎓 Назначение

Проект разработан в учебных целях в рамках курсовой работы для демонстрации принципов построения программных систем домашней безопасности с использованием сетевого взаимодействия, серверной архитектуры и баз данных.
